# ecomkit

> **English:** `ecom` lets an AI agent search, fill a cart and order from
> Russian shops and delivery services, from the command line or over MCP. Every
> order needs your confirmation and stays within spending limits you set. The
> rest of this README is in Russian.

`ecom` даёт AI-агенту искать товары, собирать корзину и оформлять заказы в
российских магазинах и доставках. Работает как CLI и как MCP-сервер. Любой
заказ требует вашего подтверждения и укладывается в лимиты трат.

## Сервисы

| Сервис                  | Вход | Поиск | Карточка | Корзина | Оформление | Заказы |
| ----------------------- | ---- | ----- | -------- | ------- | ---------- | ------ |
| [Магнит](#магнит)       | SMS  | ✅    | ✅       | ✅      | ✅¹        | ✅     |
| [Жизньмарт](#жизньмарт) | SMS  | ✅    | ✅       | —       | —          | ✅     |

¹ Собрано по API приложения, реальным заказом пока не проверялось.

## Установка

Нужен Node 20.19+ или Bun.

```bash
npm install -g @slopworks/ecomkit
ecom doctor
```

## Использование

```bash
ecom mock search молоко
ecom mock product milk-1
ecom <provider> add <id> --qty 2
ecom <provider> checkout
```

`--json` выводит результат в JSON, `ecom --help` покажет все команды.
Токены сервиса сохраняются в системный keychain командой
`ecom login <provider>`; без keychain их можно передать переменными
`ECOM_<PROVIDER>_<KEY>`.

Подключить к Claude Code как MCP-сервер:

```bash
claude mcp add ecom -- ecom mcp
```

## Магнит

Каталог Магнит Доставки привязан к магазину. После входа (см. ниже) это
магазин вашего адреса доставки. Без входа найдите магазины, которые доставляют
по вашему адресу, и выберите нужный:

```bash
ecom magnit stores 55.7539 37.6208
ecom magnit store 777885
ecom magnit search молоко
```

Вход по номеру телефона и коду из SMS:

```bash
ecom login magnit
```

Если SMS уже пришла, а ввод кода прервался, код можно ввести без новой
отправки: `ecom login magnit --code`.

После входа доступна корзина. Её магазин определяется адресом доставки,
выбранным в приложении Магнита:

```bash
ecom magnit add 1000049786 --qty 2
ecom magnit cart
```

Весовые товары продаются порциями, вес порции указан в названии: `--qty 2` у
товара «…, 300 г» положит в корзину 600 г.

Последние заказы и состав одного из них:

```bash
ecom magnit orders
ecom magnit order <id>
```

Заказ оформляется на адрес, время доставки и способ оплаты, выбранные в
приложении Магнита; в профиле должен быть указан email. Если оплата идёт
через СБП или Магнит Пэй, после заказа `ecom` покажет ссылку на оплату:

```bash
ecom magnit checkout
ecom magnit checkout --confirm <код>
```

## Жизньмарт

Поиск и карточки товаров работают без входа:

```bash
ecom lifemart search молоко
ecom lifemart product 25423
```

Вход по номеру телефона и коду из SMS. С `--code` вводится уже полученный
код без новой отправки: если ввод прервался или код запрошен на lifemart.ru:

```bash
ecom login lifemart
ecom login lifemart --code
```

Если Жизньмарт попросит капчу, запросите код на сайте и введите его через
`ecom login lifemart --code`: `ecom` капчу не проходит.

После входа доступны последние 10 заказов и состав одного из них:

```bash
ecom lifemart orders
ecom lifemart order <id>
```

Весовые товары продаются шагами, вес шага указан в названии, цена — за шаг:
«Бананы, 200 г» стоит как 200 г бананов. Наличие в поиске — общий остаток
сети, в конкретном магазине товара может не оказаться.

## Покупки

`checkout` сначала показывает состав заказа, сумму и одноразовый код. Заказ
оформляется, только когда вы передаёте этот код обратно. Код действует 10
минут и перестаёт подходить, если корзина или адрес изменились.

По умолчанию можно потратить не больше 5 000 ₽ за заказ и 10 000 ₽ за сутки.
Лимиты задаются в рублях в `~/.config/ecomkit/config.json`:

```json
{ "limits": { "perOrder": 3000, "perDay": 8000 } }
```

Лимиты защищают от ошибок агента. От агента, которому доступен ваш shell, они
не спасут: он может поменять конфиг сам.
